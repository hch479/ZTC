# 供电复核与手动转角测试准备

用户确认小车正常电池供电、主电源打开。此前已确认架空并可随时断电。

## 实际完成的检查

底盘节点停止时，通过串口发送参数20的READ请求，收到匹配序号91的成功回复：欠压阈值9800mV。此操作没有修改或保存参数。

启动独立验证节点后，在电机禁止状态下连续观察约12秒：当前电压12.221～12.222V，但LOW_BATTERY锁存仍存在。

随后先调用`/chassis/enable=false`，确认返回drive disabled，再调用`/chassis/clear_faults`。服务返回仅表示命令发出，因此又观察了20秒真实诊断，结果如下：

| 项目 | 结果 |
|---|---|
| 诊断样本数 | 101 |
| 状态 | 全部IDLE |
| 故障 | 全部NONE |
| 电压范围 | 12.214～12.217V |
| 最后控制超期计数 | 0 |
| IMU | ICM20948，500/500 |
| EKF融合 | True |
| EKF拒绝计数与gap | 均为0 |

说明清除后这20秒没有再报欠压；不代表已证明最初欠压的具体原因，也不代表电机负载下电池电压不会下降。

没有更改阈值，没有屏蔽保护，没有使能电机，没有发送运动命令。结束后停止本次测试节点，等待下一阶段现场配合。

RDK日志：`/home/wheeltec/ekf_validation_20260911/power_after_clear_20260912.txt`。

## 下一阶段需要用户配合

先做手动旋转，不启动电机。请准备车头原方向和从上方看逆时针约90°的新方向标记，可用两条互相垂直的胶带作粗略参考。

开始采样前不必转动车体；确认可以安全移动整车、支撑稳固、ST-Link和USB线长度足够，不会拉扯或缠绕。若架空支撑不允许安全手动转动，请说明，不要勉强操作。

用户确认准备好后再启动记录并发出开始提示。动作将分为：先静止、缓慢左转约90°、保持静止，再另一次缓慢右转回原方向。每次动作都需要用户报告完成，以便解释记录中的方向和阶段。

主要检查gyro z左转为正、右转为负，以及角速度积分是否与粗略转角接近。手动搬转时车轮可能不滚动，这会使编码器观测与车体运动不一致；因此不能把这个实验当作正常行驶时的EKF角度精度验收。

低速电机和地面运动测试仍未执行。
