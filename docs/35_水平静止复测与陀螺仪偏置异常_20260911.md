## 结论

用户确认车体架空、水平后，重新识别ST-Link并复位下位机，完成启动校准和完整60秒采样。通信链路正常，但六轴静止验收未通过：陀螺仪x轴存在明显假角速度，已在下位机内存中找到对应的异常校准偏置。

本次没有重新烧录、没有修改固件源码、没有使能电机、没有下发运动命令。测试结束已停止ROS测试节点，确认进程正常退出。下位机仍运行此前烧录的固件。

## 下位机只读定位证据

从实际烧录对应的AXF符号表解析地址，而不是猜测内存布局：

```text
imu             0x20006070，36字节
gstGyroOffset   0x20000118，6字节
g_imu_snapshot  0x20006094，24字节
```

通过ST-Link attach读取RAM，不写入偏置、不暂停任务修改数据。运行中读取不是原子快照，适合判断数千计数的持续偏差，不应过度解释个别计数差。

第一次读取：

```text
imu.Deviation_gyro.x = 0x1266 = 4710
imu.Original_gyro.x  = 0xFFF8 = -8
imu.gyro.x           = 0xED92 = -4718
gstGyroOffset.s16X   = 0xFFF6 = -10
```

对应源码`ICM20948_Get_Gyroscope()`：

```c
imu.gyro.x = imu.Original_gyro.x - imu.Deviation_gyro.x;
```

即`-8 - 4710 = -4718`。按当前65.5 LSB/(°/s)换算约−1.257rad/s，与ROS实测一致。因此持续假角速度已经存在于下位机校正输出中，不是ROS单位换算引入。

注意：`Original_gyro`不是直接的寄存器裸读数，它已经经过8点平均和第一层`gstGyroOffset`扣除。

为了检查可重复性，在车体持续静止条件下再次复位；待校准完成后只读RAM：

```text
imu.Deviation_gyro.x = 0x126D = 4717
imu.Original_gyro.x  = 2
imu.gyro.x           = -4715
gstGyroOffset.s16X   = -19
快照校准进度          = 500/500
```

第二次出现相近异常偏置，说明不是仅一次ROS消息的偶然异常。第二次复位后没有重新做60秒ROS采样，不能把第一次采样统计套用到第二次。

## 尚未确定的根因和后续方向

已定位到第二级校准偏置与稳定后的读数不匹配，但尚未记录启动500点逐样本数据，不能直接断言是器件损坏、I²C故障、启动瞬态或内存问题。

当前校准实现只预热50点，然后无条件平均500点；没有先检测读数是否稳定，也没有异常样本拒绝或校准结果合理性检查。因此`500/500`目前只表示收集数量完成，不等于校准质量通过。

下一步应在保持电机禁止的情况下记录启动样本与校准累积过程，检查I²C读取及数据有效性，再基于证据改进校准质量判定。不能只手动把4710减掉，也不能只延长预热时间就宣布修复。

在这个问题解决前，不进入电机运动或动态融合验收。RDK时间仍为2000年，尚未修正；本轮频率和统计使用单调时间，正式录包/TF时间验收仍待完成。
