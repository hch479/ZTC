# 实车标定与调参

## 1. 为什么默认参数不能直接当最终参数

资料中说明了 GMR 500 线编码器和多种车体，但同一套 C30D 代码支持不同轮径、减速比、轮距和车型；电机静摩擦、左右负载、电池电压也各不相同。默认值只保证范围保守和代码可运行，不等于对你的车完成辨识。

## 2. 先标定硬件方向

驱动轮离地、限速 0.08 m/s。正线速度时：

- 左右轮机械方向都应是车体向前；
- `/motor/debug` 中左右目标均为正；
- 左右实际速度均为正；
- 编码器累计值均增加。

若机械方向错，改 `C30D_*_PWM_SIGN`；若机械正确但速度符号错，改 `C30D_*_ENCODER_SIGN`。改完重新编译固件，不在 ROS 层修符号。

## 3. 每圈编码器计数

1. 失能电机。
2. 在轮胎和车架上各做一条对齐标记。
3. 记录 `/joint_states` 或 `candump` 中初始累计计数。
4. 手动让一个轮子向前精确转 10 圈。
5. `counts_per_wheel_rev = (结束计数 - 开始计数) / 10`。
6. 左右分别测量，若差异超过约 1%，检查漏计数、线序和机械松动。

理论 60000 只用于结果合理性判断，实测优先。

## 4. 有效轮径与轮距

用软尺测出的轮径是起点；带载后轮胎变形会改变有效周长。

### 轮径

让车低速直行较长距离，例如 5 m。若 ROS 里程计为 `L_odom`，实际距离为 `L_real`：

```text
新轮径 = 旧轮径 * L_real / L_odom
```

至少往返各做三次取平均，避免起停和地面打滑影响。

### 轮距

差速车原地缓慢转若干整圈。若实际总角度为 `yaw_real`、里程计为 `yaw_odom`：

```text
新轮距 = 旧轮距 * yaw_odom / yaw_real
```

阿克曼车不要原地转，用定半径圆周测量，并同时标定轴距和舵机转角映射。

## 5. 测死区和前馈

先把 `kp=ki=0`，直行同步也置零。缓慢提高正向 PWM，记录车轮能够持续转动的最小值，得到 `dead_forward`；反向同理。

然后选取多个目标速度，例如 0.1、0.2、0.3、0.4 m/s，记录稳定所需 PWM。粗略斜率：

```text
Kff = (PWM_high - PWM_low) / (speed_high - speed_low)
```

正反转差异较大时，本版用不同死区处理；若仍不够，可后续扩展为正反两个 Kff。

## 6. 调 PI

每次只调一个轮，驱动轮离地开始，落地低速复核。

1. `Ki=0`，Kff 和死区使用上一步结果。
2. 从较小 Kp 开始，逐步增加，直到阶跃响应跟随较快但不持续振荡。
3. 加入较小 Ki，消除带载后的稳态误差。
4. 如果过冲明显，先减 Ki；高频抖动则减 Kp 或适度降低 `filter_alpha`。
5. 检查正转、反转、低电量和载荷变化，不只看一个工况。

`filter_alpha` 越大越相信本周期原始测速，响应快但噪声大；越小越平滑但延迟大。常用试验范围 0.2~0.6。

## 7. 调直行同步

PI 稳定后再打开同步：

1. `straight_sync_kp=0` 做多次 3~5 m 直行，记录偏差。
2. 从 0.1 开始增加同步 Kp。
3. 如果左右目标来回摆动，减小 Kp 或 `straight_sync_max_mps`。
4. 直行同步只能补偿驱动差异，不能修复松动轮胎、偏斜车架或严重轮径误差。

阿克曼车型还需单独标定舵机。先在电机失能时找到机械正中 PWM，再小步改变 PWM 并测量实际前轮转角。若正角速度时车向错误方向转，可将 `servo_pwm_per_rad` 设为负值；不要调换舵机电源线。

## 8. 堵转参数

默认条件是：目标至少 0.15 m/s、实测不超过 0.02 m/s、PWM 达上限 80%，持续 600 ms。测试时不要徒手长时间抓住轮胎。使用可控负载或短时软障碍，确认：

- 普通起步不会误报；
- 真实卡住时能在规定时间停机；
- 清除障碍并失能后可以清故障；
- 电机和驱动芯片温升可接受。

## 9. 推荐记录的数据

用 rosbag 记录：

```bash
ros2 bag record /cmd_vel /odom /joint_states /motor/debug /diagnostics
```

从 `/motor/debug` 画目标/实际速度、误差和 PWM 曲线，计算上升时间、超调、稳态误差和左右同步误差。这些曲线和测试数据比“实现了电机控制”一句话更能体现项目深度。
