# 串口版实机操作

## 1. 当前连接

小车原有 USB 串口已经连接到 RDK X5。厂家 udev 资料约定：

- 序列号 `0002`：底盘控制器；
- 序列号 `0001`：雷达。

本项目因此使用稳定设备路径：

```text
/dev/serial/by-id/usb-WCH.CN_USB_Single_Serial_0002-if00
```

不要直接依赖 `/dev/ttyACM0`，因为设备编号可能在重启后交换。

## 2. 通信参数与帧格式

USART3 使用 `115200 baud、8 data bits、no parity、1 stop bit、no flow control`。

每个串口包固定 15 字节：

```text
A5 5A | version | logical_id低 | logical_id高 | 08 | data[8] | CRC8
```

CRC 为 CRC-8/ATM，对 `version` 至 `data[7]` 共 12 字节计算。`logical_id + data[8]`
沿用 CAN 版协议，因此运动命令、参数、遥测和 ROS 话题在两种物理通信方式下保持一致。

## 3. 编译与烧录下位机

1. 将轮子架空，电机硬件使能关闭。
2. 打开 `keil_project/R550_C30D_SERIAL_MOTOR/USER/WHEELTEC.uvprojx`。
3. Rebuild，必须为 `0 Error(s), 0 Warning(s)`。
4. 输出是 `OBJ_SERIAL/C30D_SERIAL_MOTOR.hex`。
5. Flash Download 选择 `Erase Sectors`、`Program`、`Verify`、`Reset and Run`。
6. 不选择 `Erase Full Chip`；链接脚本会保留 `0x08060000..0x0807FFFF` 参数区。

若需恢复，使用 `hardware_backups/C30D_20260813/C30D_factory_full_read1.bin`，地址
`0x08000000`。恢复整片前必须先重新备份当前 Flash。

## 4. RDK X5 启动

代码位于：

```text
/home/wheeltec/chassis_project/ros2_ws
```

安全启动（启动后仍为软件失能）：

```bash
cd ~/chassis_project/ros2_ws
bash src/chassis_can_control/scripts/start_chassis_serial_safe.sh
```

另开终端检查：

```bash
source /opt/ros/humble/setup.bash
source ~/chassis_project/ros2_ws/install/setup.bash
ros2 topic echo /diagnostics
ros2 topic echo /motor/debug
```

只有确认心跳和状态正常、车轮全部离地后，才允许：

```bash
ros2 service call /chassis/enable std_srvs/srv/SetBool "{data: true}"
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.05}, angular: {z: 0.0}}"
```

停止：

```bash
bash ~/chassis_project/ros2_ws/src/chassis_can_control/scripts/stop_chassis_serial_safe.sh
```

STM32 还会在 200 ms 没收到有效命令时自动令目标速度归零。

## 5. 换回 CAN

CAN 版未删除，仍在 `keil_project/R550_C30D_CAN_MOTOR`；RDK 上的
`chassis_can.launch.py`、`setup_can.sh`、`start_chassis_safe.sh` 也保留。等 CAN 线到货后，
烧录 CAN 版固件并启动 CAN launch 即可，不需要重写控制算法和 ROS 接口。
