ST-Link序列号：`37FF71064E57343659911043`。目标：`stm32f407vetx`。

烧录文件：`keil_project/R550_C30D_SERIAL_MOTOR/OBJ_SERIAL/C30D_SERIAL_MOTOR.hex`，此前Keil全量编译为0错误、0警告。

实际执行的烧录命令（从ZTC_GitHub根目录）：

```powershell
python -m pyocd flash --no-config -u 37FF71064E57343659911043 -t stm32f407vetx -f 1000000 -e sector keil_project/R550_C30D_SERIAL_MOTOR/OBJ_SERIAL/C30D_SERIAL_MOTOR.hex
```

此命令会写Flash并复位启动，不能作为普通只读检查随意重复执行。工具报告擦除5个扇区、131072字节，编程74752字节（含编程页填充）。未整片擦除，未改写选项字节。

## 4. 第一次静止采样结果

订阅器运行窗口设为60秒，但测试节点先达到110秒自动退出上限，所以实际有数据时段约54.52秒，不能称为完整一分钟连续采样。

| 项目 | 实测 |
|---|---:|
| IMU消息数 | 2728 |
| 融合odom消息数 | 1091 |
| 纯编码器odom消息数 | 1091 |
| IMU平均接收频率 | 50.019 Hz |
| gyro z均值 | 0.00013528 rad/s |
| gyro z总体标准差 | 0.00036390 rad/s |
| gyro z最小值 | −0.00133231 rad/s |
| gyro z最大值 | 0.00159877 rad/s |
| 加速度x均值 | 0.0000362 m/s² |
| 加速度y均值 | −2.82530 m/s² |
| 加速度z均值 | 9.79340 m/s² |

纯编码器和融合odom的x、y均保持0。融合yaw从约0.0085523变化到0.0151370 rad，差约0.0065847 rad（0.377°）。这些是采样首末值，不是已知角度基准下的精度标定。

角速度接近零、消息频率符合当前50Hz上传设计。但是加速度y存在明显非零值，不能只因校准显示500/500就宣布加速度校准正确。

当前校准代码把启动时平均值作为偏置，默认车体水平，并把z轴恢复为1g。校准期间移动、校准后姿态变化，以及底层读数问题都可能影响结果。仅凭本轮均值还不能判定具体原因；也不能直接把这个y值当作真实倾角反算。
