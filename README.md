# C30D 电机闭环与 ROS 2 串口/CAN 控制项目

GitHub 仓库保存开发源码、Keil 工程配置、测试及教程。原交接包中的设备备份、历史固件、原厂参考资料、SHA-256 交付清单及编译缓存仅保留在本地，不纳入 Git。文档中的旧电脑路径和设备信息属于历史记录，使用前按当前环境核对。

日常 Git 操作见 [GitHub 推送与 VS Code 使用说明](docs/26_GitHub推送与VSCode使用说明.md)。

2026-09-10：串口 ROS 配置默认使用五状态平面 EKF，`odometry.mode: weighted` 可切回原固定权重算法。EKF 使用编码器速度观测和逐条 IMU 角速度观测，发布纯编码器对照话题与带协方差的融合里程计。实现、参数、离线测试及实车验证边界见 [EKF 实现与使用说明](docs/27_EKF五状态融合实现与使用说明.md)。

本项目面向现有硬件：WHEELTEC C30D（STM32F407）运动控制板、带 AB 相编码器的直流减速电机、AT8236 电机驱动和 RDK X5 上位机。

它在原底盘基本电机代码之上补齐了一条完整、可解释、可测试的控制链路：

1. RDK X5 接收 ROS 2 `/cmd_vel`。
2. 上位机将速度命令编码为带序号和 CRC8 的串口或 CAN 报文。
3. STM32 完成车体运动学、速度斜坡、编码器测速、前馈 + PI 闭环、直行同步和 PWM 输出。
4. STM32 检查命令超时、急停、欠压、编码器异常和堵转。
5. 编码器、轮速、PWM、故障、里程计等数据返回到 RDK，并在 ROS 2 中发布。
6. 板载 MPU6050/ICM20948 完成静止校准并发布 `/imu/data_raw`；串口主线通过 EKF 融合轮速和陀螺仪观测，IMU 断流时继续使用车轮观测。

工程目录：

- `keil_project/R550_C30D_SERIAL_MOTOR/`：当前串口版 Keil 完整工程；电机版本曾实机验证，最新 IMU 融合版本仍需按专项手册烧录和验证轴向。
- `keil_project/R550_C30D_CAN_MOTOR/`：保留的经典 CAN 版 Keil 完整工程。
- `common/`：STM32 与 RDK X5 共用的 CAN 协议定义。
- `firmware/stm32f407/`：不依赖动态内存的电机控制核心，以及接入 C30D 原工程的接口层。
- `ros2_ws/src/chassis_can_control/`：运行在 RDK X5 上的 ROS 2 Python 包，支持串口和 SocketCAN。
- `tests/`：可在电脑上运行的 C 单元测试。
- `docs/`：原理、协议、接线、接入、调参和测试说明。

上下位机代码讲解统一位于 [docs/模块讲解_融合版](docs/模块讲解_融合版)，其中按下位机 1～8、上位机 1～8 分成 16 份可独立打开的文档；每份都已经融合该模块首次讲解后的继续追问。串口版入口为 `keil_project/R550_C30D_SERIAL_MOTOR/USER/WHEELTEC.uvprojx`。IMU 新功能的烧录、轴向确认与验收见 [docs/21_IMU融合实现与实车操作手册.md](docs/21_IMU融合实现与实车操作手册.md)，改动清单见 [docs/22_IMU改动清单与ICM20948数据读取使用详解.md](docs/22_IMU改动清单与ICM20948数据读取使用详解.md)。如果此前完全没学过 IMU，请先读 [docs/23_零基础认识IMU与ICM20948底层驱动逐层详解.md](docs/23_零基础认识IMU与ICM20948底层驱动逐层详解.md)，再读 [docs/24_零基础从IMU底层数据到ROS与编码器里程计融合详解.md](docs/24_零基础从IMU底层数据到ROS与编码器里程计融合详解.md)。第一次改写程序前还要阅读 [docs/09_CANFD与烧录恢复.md](docs/09_CANFD与烧录恢复.md)。不要直接运行未经标定的电机参数。

代码复查后的默认配置按 R550 Mini 资料设置为阿克曼结构、65 mm 轮径、162 mm 轮距、144 mm 轴距和 60000 count/rev；节点启动时软件使能默认为关闭。实车第一次运行仍需完成方向、计数和舵机标定。

> 安全提示：首次测试必须让驱动轮离地，准备随时断开电机电源。不同批次底盘的电机线序、编码器方向和减速比可能不同，必须先完成方向与计数标定。
